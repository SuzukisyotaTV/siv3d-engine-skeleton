# siv3d-engine-skeleton

Week1: Minimal ECS demo with Siv3D.

Build / Run:
- Open this folder in Visual Studio (File -> Open -> Folder) or create a new C++ project and add `src/` and `include/`.
- Make sure Siv3D is installed and its include/lib paths are configured in Project Properties.
- Build and run.

Controls:
- Space: Pause / Unpause
- R: Re-randomize positions

Files:
- include/ecs.hpp : minimal ECS
- src/main.cpp : demo application
